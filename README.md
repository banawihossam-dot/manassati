# منصتي – أوراق العمل التفاعلية الجماعية

منصة يصمّم فيها المعلم أوراق عمل، ويدخلها الطلاب **بالاسم والرمز فقط دون حساب**، ويحلّونها معًا في الوقت الفعلي.

## ما الذي يعمل في هذه النسخة

**المعلم:** حساب بالبريد، إنشاء أوراق العمل وتعديلها ونسخها، 14 نوعًا من الأسئلة والأنشطة، رفع الصور والفيديو أو روابط YouTube، معاينة كما يراها الطالب، حفظ تلقائي، أرشيف لكل الأنشطة ونتائجها.

**أنواع الأسئلة:** اختيار من متعدد (إجابة واحدة أو أكثر)، صح أو خطأ، إجابة قصيرة مع بدائل مقبولة، إجابة مقالية، إكمال الفراغ، توصيل، ترتيب، سحب وإفلات (تصنيف)، سؤال على صورة بمواضع مرقّمة، نص طويل بعدة مربعات، جدول تعبئة جماعية، خريطة مفاهيم، لوحة تفكير جماعي وحل مشكلات، ونص أو وسائط بلا سؤال.

**العمل الجماعي:** ثلاثة أنماط (كل طالب مستقل، مجموعات، مساحة مشتركة للصف)، توزيع تلقائي أو عشوائي أو يدوي على المجموعات، ظهور اسم كاتب كل مشاركة، تحديث فوري دون إعادة تحميل الصفحة، إظهار إجابات الزملاء أو إخفاؤها، معرفة من يشارك ومن لم يشارك ومن هو متصل الآن، محادثة جماعية يمكن إيقافها، وحفظ تلقائي للإجابات حتى عند انقطاع الإنترنت (تُرسل عند عودة الاتصال).

**التصحيح:** تلقائي لكل الأنواع القابلة لذلك (مع تجاهل الهمزات والتشكيل والتاء المربوطة عند المقارنة، ودرجات جزئية)، ويدوي مع ملاحظات لكل سؤال وملاحظة عامة وتعديل الدرجة النهائية، وبمساعدة الذكاء الاصطناعي: يقترح درجة وسببها وتغذية راجعة، **ولا تُعتمد إلا بضغط المعلم على «اعتماد»**. لا تُرسل أسماء الطلاب إلى الذكاء الاصطناعي.

**النتائج:** عدد المشاركين، نسبة الإنجاز، المتوسط، نقاط القوة ومواضع الصعوبة، نسبة الإتقان لكل سؤال، مقارنة المجموعات، مشاركة كل طالب، تصدير Excel (أربع أوراق)، وتقرير للطباعة أو الحفظ PDF.

**الطالب:** دخول بالاسم والرمز أو برابط مباشر، شريط إنجاز، حالة الحفظ، إشعار عند انتهاء النشاط، ورؤية النتيجة والملاحظات والإجابات الصحيحة إذا سمح المعلم.

**الحماية:** كل صلاحية مفروضة في قاعدة البيانات نفسها (Row Level Security). الإجابات النموذجية لا تصل إلى أجهزة الطلاب أبدًا قبل انتهاء النشاط، والطالب لا يرى زملاءه أو إجاباتهم إلا إذا سمح المعلم، ولا يرى درجته إلا بعد نشر النتائج.

## النشر على GitHub Pages

قاعدة البيانات جاهزة على Supabase، ومفاتيح الاتصال العامة مضبوطة داخل الكود، فلا حاجة لإضافة أي متغيرات.

1. ارفع محتويات هذا المجلد إلى مستودع GitHub باسم `manassati`، ويجب أن يكون **Public** لأن GitHub Pages مجاني للمستودعات العامة. لا يحتوي الكود على أي أسرار.
2. من المستودع: **Settings ← Pages**، وفي **Source** اختر **GitHub Actions**.
3. تأكد أن الملف `.github/workflows/deploy.yml` موجود في المستودع. سيبني الموقع وينشره تلقائيًا مع كل تعديل، وتتابع ذلك من تبويب **Actions**.
4. يصبح الموقع على: `https://<اسم-المستخدم>.github.io/manassati/`
5. في Supabase: **Authentication ← URL Configuration**، ضع رابط الموقع في **Site URL**، وأضف `رابط-الموقع/**` في **Redirect URLs**.
6. في Supabase: **Authentication ← Sign In / Providers**، فعّل **Allow anonymous sign-ins** ليدخل الطلاب دون حسابات.

> **التصحيح بالذكاء الاصطناعي:** يعمل عبر الدالة `supabase/functions/ai-grade` المنشورة على Supabase. لتفعيله أنشئ مفتاحًا من console.anthropic.com، ثم أضفه في Supabase: **Edge Functions ← Secrets** باسم `ANTHROPIC_API_KEY`.

> إن غيّرت اسم المستودع، فغيّر `/manassati` في `next.config.mjs` و`.github/workflows/deploy.yml` إلى الاسم الجديد.

## طريقة الاستخدام في الحصة

1. أنشئ ورقة العمل وأضف الأسئلة. لكل سؤال مقالي اكتب الإجابة النموذجية ومعايير التقييم إن أردت التصحيح بالذكاء الاصطناعي.
2. اضغط **ابدأ نشاطًا** واختر نمط العمل والإعدادات.
3. اضغط **عرض للصف** ليظهر الرمز كبيرًا على السبورة الذكية. يدخل الطلاب من الصفحة الرئيسية بالرمز وأسمائهم.
4. تابع من **المتابعة المباشرة**: من انضم، ومن يشارك، والإجابات سؤالًا سؤالًا.
5. عند الانتهاء اضغط **إنهاء النشاط**، ثم صحّح من **التصحيح**، ثم **نشر النتائج للطلاب** من تبويب النتائج.
6. صدّر Excel أو افتح التقرير واحفظه PDF.

## ملاحظات مهمة

- هوية الطالب مرتبطة بالمتصفح الذي دخل منه. إن أغلق الصفحة وعاد من الجهاز نفسه بالاسم نفسه تعود إجاباته. على الأجهزة المشتركة، يبدأ كل اسم جديد هوية جديدة.
- الخطة المجانية في Supabase تكفي لصفوف عادية، لكنها تضع حدًا لعدد الاتصالات الفورية المتزامنة، وتوقف المشروع مؤقتًا إذا لم يُستخدم أسبوعًا (يُعاد تشغيله من لوحة Supabase بضغطة). راجع حدود الخطة الحالية في موقع Supabase.
- لتقليل إساءة استخدام الدخول المجهول يمكنك لاحقًا تفعيل CAPTCHA من إعدادات Authentication في Supabase.

## التشغيل على جهازك (للمطورين)

```bash
npm install
cp .env.example .env.local   # ثم ضع المفاتيح
npm run dev                  # http://localhost:3000
```

## بنية المشروع

```
supabase/schema.sql          الجداول والصلاحيات ودالة انضمام الطالب والمزامنة الفورية
src/lib/questions.ts         أنواع الأسئلة، إخفاء الإجابات، التصحيح التلقائي
src/lib/results.ts           إطلاق النشاط وحساب النتائج والتحليلات
src/app/page.tsx             الصفحة الرئيسية ودخول الطالب
src/views/StudentWorkspace    مساحة عمل الطالب
src/app/teacher              لوحة المعلم، محرر الأوراق، المتابعة والتصحيح والتقارير
supabase/functions/ai-grade  التصحيح بمساعدة الذكاء الاصطناعي
src/components               مكونات الواجهة
```

التقنيات: Next.js 14، وTailwind CSS، وSupabase (قاعدة بيانات Postgres، ومصادقة، ومزامنة فورية، وتخزين ملفات)، وClaude API للتصحيح المساعد.
